# TereTube Theme

A light, color-led Omarchy community theme by **@terelux**. Its palette uses deep ink `#253439`, burnt orange `#AA4B00`, and warm ivory `#F3EFE7`. The five included wallpapers explore that palette with abstract flow, strata, waves, and geometric compositions.

This is an independent community theme. It is not an official Omarchy or OpenAI release, and neither project endorses it.

## Install

After this folder is published as a public GitHub repository:

```sh
omarchy theme install https://github.com/IlTere/omarchy-teretube-theme
```

The icon theme is `Yaru-yellow`, one of Omarchy's listed Yaru variants.
